# 인공지능응용 | AI Applications

tinytrack 시뮬레이터를 활용해 자율주행 모델을 학습하고,
다양한 주행 조건에서 성능을 비교한 수업 실습·과제 저장소입니다.

## 주요 내용

- **데이터 처리** — 주행 데이터 정제, 학습·검증 데이터 분리, 조향값 분포 조정
- **모방학습** — 전문가의 조향을 학습하고, DAgger로 차선 복구 데이터 추가
- **모델 평가 및 배포** — ONNX 변환, 폐루프 주행 평가, 외란 조건별 성능 비교
- **강화학습** — PPO를 이용한 주행 정책 미세조정과 보상 설계

## 실행 방법

실습 및 과제 노트북(`.ipynb`)을 Google Colab에서 열고,
각 노트북의 환경 설정 셀부터 순서대로 실행합니다.
